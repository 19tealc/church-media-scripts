Optional: find the live stream automatically

YouTube retired the old “whatever is live on this channel” embed, so the only way to auto-find your stream now is a free YouTube Data API key. Add one and you can put a channel link or @handle in the box above — the page finds the live video on its own, every service, with nothing to paste.

  1. Go to console.cloud.google.com and create a project (free).
  2. APIs & Services → Library → enable YouTube Data API v3.
  3. Credentials → Create credentials → API key. Copy it below.
  4. Restrict the key to the YouTube Data API. Leave the website restriction off, or the key won't work from a local file.
Stored only in this browser; sent only to Google.
Tips & troubleshooting
  • Everything starts muted. Browsers block autoplay with sound, so pick one source with the Audio buttons once the page loads.
  • Switching Facebook audio reloads that player (it jumps to the live edge). YouTube mutes instantly, no reload.
  • YouTube says playback is disabled? In YouTube Studio, open the stream and turn on Allow embedding.
  • Facebook panel blank? Facebook's embed often refuses to load from a file:// page. Serve the folder instead: run python3 -m http.server 8000 in this folder, then open http://localhost:8000. Private or unlisted FB videos can't be embedded at all.
  • Bookmarkable: add ?yt=...&fb=... to the page URL to override the saved values.
  • Keys: 1 YouTube audio · 2 Facebook audio · 0 mute both · R reload · S settings · Esc close.
